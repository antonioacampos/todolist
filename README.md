# TodoList - Lista de Tarefas
Este projeto é uma aplicação simples de lista de tarefas (TodoList) desenvolvida em Java. Ele permite criar, visualizar e excluir tarefas diretamente do console.

## Funcionalidades
### Adicionar Tarefas: Adicione novas tarefas à sua lista.
### Listar Tarefas: Visualize todas as tarefas atuais.
### Atualizar status: Modifique o status de progresso de uma tarefa específica.
### Excluir Tarefas: Remova tarefas específicas da lista.
### Limpar Tarefas: Remova todas tarefas  da lista.
